# Сервер SS12 для Linux

*[English version](README.md)*

Готовый к запуску игровой сервер Space Station 14 с 3D-видом SS12 для Linux (64-битные Intel/AMD). Это оригинальная игра
той версии, что указана в описании релиза, собранная с HybridACZ: игроки заходят через обычный лаунчер, а 3D-клиент
скачивается с вашего сервера сам.

Нужен свежий 64-битный Linux с `glibc`, `unzip` и свободный TCP/UDP-порт (по умолчанию 1212). Устанавливать .NET **не
нужно**: он уже внутри архива.

## Запуск

```bash
unzip SS12-server-linux-x64.zip -d ss12-server
cd ss12-server
./run-server.sh
```

При первом запуске создаются `server_config.toml` (из `server_config.example.toml`) и папка `data/`. Отредактируйте
конфиг (название, порт, правила) и перезапустите. Остановка: `Ctrl+C`.

## Запуск как службы

`ss12.service` — это юнит systemd. Команды установки указаны в начале файла. Он рассчитан на папку `/opt/ss12` и
пользователя `ss12`.

## Как подключиться

Откройте лаунчер Space Station 14, выберите *Direct connect* и введите `ваш-адрес:1212`. С того же компьютера —
`127.0.0.1:1212`. Для публичного сервера также задайте `status.connectaddress` в конфиге, чтобы лаунчер мог его найти.

## Что проверено

Рабочий процесс релиза запускает именно этот сервер на Linux-раннере и ждёт, пока он сообщит о готовности и начнёт
принимать подключения. Подключиться к SS12-серверу на Linux настоящим клиентом пока никто не пробовал; если у вас
получится, расскажите об этом в [issue](https://github.com/Ehab-0/ss12/issues/new/choose).
