# Helping out

*[Русская версия](CONTRIBUTING.ru.md)*

You do not need to write code to help.

- **Try it and tell us.** The most useful thing is an honest report: what felt good, what felt wrong (mouse feel, speed,
  looks, anything), on what computer.
- **Test it on a server** you run or play on, and tell us whether it worked.
- **Share screenshots.**

If you do write code, read [docs/FOR-DEVELOPERS.md](docs/FOR-DEVELOPERS.md). Please keep changes small and tell us how you
tested them. By contributing you agree to licence your work under the MIT licence of this project.

**AI assistants and agents:** read [AGENTS.md](AGENTS.md) before you open an issue or a pull request. Please do not open
issues or pull requests in bulk, for style, or for ideas nobody asked for.

Be kind. Everybody started somewhere.
